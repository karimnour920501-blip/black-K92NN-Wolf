# BLACKWOLF K92N 1.0.2 — تجهيز تجربة المشغّل قبل الدفع

المرجع: main بعد دمج PR #38؛ الأساس 8e8ab4f4f4e3264da4678e53c28cbc90db9d4909.
هذه نسخة تجربة لمشغّل واحد ببيانات وهمية. لا اشتراك ولا شراء ولا نشر سحابي تلقائي في هذا التغيير.

## ما أصبح متاحًا للمشغّل

- شاشة عربية مناسبة للهاتف: اتصال، إعداد حسابات، دين، دفعة، كشف عميل، عكس قيد، فحص نزاهة، وتصدير الحركات المحمّلة CSV.
- المبالغ تمر كنصوص عشرية إلى C#؛ العرض يحسب من وحدات صغرى صحيحة باستخدام BigInt. الكسور الزائدة تُرفض ولا تُقرّب. أرقام لوحة المفاتيح العربية والفاصل العشري ٫ تُوحّد صراحة؛ الفواصل الملتبسة وتجميع الآلاف لا يُخمّن معناها.
- أرصدة مستقلة لكل عملة ولكل عميل وحساب. للحركة الأجنبية تُدخل القيمة الأساسية USD صراحة؛ لا خدمة أسعار صرف أو جلب أسعار آلي.
- عند ضياع رد عملية محاسبية، تتوقف عمليات جديدة ويُعاد تأكيد العملية نفسها بمفتاح idempotency ومحتوى ثابتين.
- الرمز في ذاكرة الصفحة فقط، مع إلغاء الطلبات القديمة ومسح العرض عند الخروج. لا تحفظ الواجهة أسرارًا أو قيودًا في localStorage/sessionStorage.
- القيود الأصلية تبقى، والعكس حركة جديدة. عكس دين مسدد جزئيًا قد يظهر رصيدًا دائنًا سالبًا؛ تعرضه الواجهة صراحة.
- كشف مقسّم إلى صفحات من السطور المختومة فقط، بترتيب ومستعرض cursor ثابتين. CSV للحركات المحملة فقط، وليس نسخة احتياطية. الحقول التي قد تعمل كصيغ جداول تُحيد.

العميل هنا رقم مرجعي؛ إدارة أسماء وملفات العملاء غير منفذة. لا تسجيل ذاتي ولا اشتراكات ولا متجر تطبيقات ولا تشغيل أوفلاين ولا PWA. لم يتحول المضيف إلى خدمة متعددة المتاجر. تسجيل الأحداث القديمة لا يملك idempotency؛ افحص سجل الأحداث بعد رد ضائع قبل إعادة الإرسال.

## تجربة محلية بلا اشتراك

تحتاج كمبيوتر Linux/.NET 10؛ تنزيل المصدر على iPhone لا يشغّل خادم C# عليه.
من apps/k92n:

```bash
dotnet restore src/K92N.Host/K92N.Host.csproj --locked-mode
dotnet build src/K92N.Host/K92N.Host.csproj -c Release --no-restore
python3 tools/pilot_local.py
```

البرنامج يعمل على http://127.0.0.1:5080 فقط. يولّد رمزًا في `.runtime/operator-token` بصلاحية 0600، ولا يطبعه في السجل. اقرأه محليًا وأدخله في الصفحة، ولا ترسله في الدردشة أو تلتقطه في صورة منشورة. قاعدة التجربة في `.runtime/data`.
لا يصل هذا الرابط من هاتف بعيد؛ يلزم HTTPS/استضافة أو نفق SSH موثوق. لا تفتح HTTP عامًا ولا ترسل الرمز عليه.

أو شغّل Docker Compose على كمبيوتر يدعم Docker:

```bash
# عيّن K92N_OPERATOR_TOKEN محليًا بسر عشوائي طويل عبر آلية الأسرار لديك.
docker compose -f infra/compose.pilot.yaml up -d --build
```

Compose ينشئ قرصًا محليًا خاصًا بالمشروع، ويهيّئ ملكيته بحاوية تجهيز مؤقتة ثم يشغّل التطبيق بغير root، ويربط المنفذ بـloopback فقط. لا ينشئ خادمًا سحابيًا. لا تستخدم `down --volumes` على بيانات تريد الاحتفاظ بها. تهيئة ملكية القرص هنا لا تثبت صلاحيات /data في Render.

## خطوات تجربة صاحب الدفتر

1. اتصل برمز المشغّل؛ أنشئ 1 / 1000 / الصندوق، ثم 2 / 1200 / ذمم العملاء من «إعداد الحسابات».
2. اختر العميل 7، وحساب الذمم 2، والحساب المقابل 1.
3. أضف دين USD بقيمة 125.50، ثم دفعة 25.50؛ يجب أن يصبح الرصيد 100.00 USD.
4. أضف دين TRY بقيمة 100.00 وقيمة أساسية 3.25 USD؛ يجب ظهور رصيد TRY منفصل.
5. اعرض السجل وتحقق من التواريخ والأوصاف، وصدّر الصفحات المحملة. لا تعتبر CSV نسخة قابلة لاستعادة الدفتر.
6. اختبر رفض صفر وسالب وكسور زائدة. يجب ألا تظهر حركة محفوظة جديدة بعد الرفض.
7. اختبر العكس ببيانات وهمية وراقب الرصيد الدائن المحتمل؛ لا تحذف الأصل.
8. افصل الاتصال ثم أعد فتح الصفحة؛ أعد إدخال الرمز واعرض الكشف. هذه قراءة جديدة من الخادم وليست استعادة من ذاكرة المتصفح.
9. بعد رد حفظ ضائع أعد التأكيد من زر المحاولة السابقة. إذا أغلقت الصفحة أو تعطّل الهاتف قبل التأكيد، افحص الكشف قبل إعادة إدخال الحركة؛ مفتاح المحاولة في الذاكرة لا ينجو من إغلاق الصفحة.

## التحقق الآلي قبل الدفع

```bash
python3 tools/pilot_smoke.py
node --test tests/money.test.mjs
npm ci --ignore-scripts
npx --no-install playwright install --with-deps chromium webkit
node tests/browser/pilot.cjs
python3 tools/recovery_ci.py
```

اختبار المتصفح يستخدم خادم C# حقيقيًا وقاعدة مستقلة وواجهة بعرض هاتف. يفحص الدين والدفعة والعكس، عدم تنفيذ الوصف كشيفرة، ضياع الرد بعد اعتماد القيد، إعادة المحاولة دون تكرار، إعادة الفتح، والخروج أثناء رد متأخر. Chromium/WebKit هنا محاكاة هاتف على Linux، وليسا Safari على iPhone فعلي.
أدوات npm للاختبار فقط، مثبتة بإصدار محدد وملف قفل SHA-512؛ لا تُنسخ إلى صورة التطبيق. فحص npm لا يغني عن فحص الحزم الأصلية أو OS.

## التشغيل والاستعادة

`pilot_preflight.py` فاحص قراءة فقط لـHTTPS أو loopback؛ لا يرحل قيودًا ولا يتبع إعادة توجيه قد تنقل الرمز لمضيف آخر:

```bash
python3 tools/pilot_preflight.py https://YOUR_REAL_HOST
```

يأخذ الرمز من K92N_OPERATOR_TOKEN ولا يقبله في عنوان URL. يفحص الصحة ورفض الدخول دون رمز وCache-Control والنزاهة والعملات. لا يختبر Restart/Redeploy أو الهاتف الفعلي.
لنسخ واستعادة SQLite اتبع عقد الاستعادة في DEPLOYMENT-HARDENING-1.0.1.md. احتفظ بالنسخة والمرجع خارج قرص الخدمة، واستعد إلى مسار جديد ثم افحص /api/integrity والأرصدة. لا يستبدل هذا التغيير قاعدة قديمة ولا يغير مخطط المحاسبة.

## ما لا يمكن إغلاقه بمجرد كتابة ملفات

| البوابة | المطلوب |
|---|---|
| استضافة فعلية | حساب وخادم وHTTPS ثم فحص بقاء البيانات بعد Restart وRedeploy |
| iPhone فعلي | فتح الرابط في Safari، تفاعل فعلي وحفظ وإعادة فتح وتنزيل CSV |
| اعتماد محل حقيقي | تجربة تشغيل يومية ونسخ واستعادة ومراجعة سهولة الاستخدام |
| متاجر متعددة | هويات وصلاحيات وعزل مستقل متحقق؛ ما زال DEFERRED |
| جاهزية الإنتاج | قبول موثق للبوابات المقصودة؛ ما زالت FALSE |

الدفع مؤجل. نجاح CI يغلق نطاق الاختبار الذي نفذه فقط؛ لا يجعل الدفع الخطوة الوحيدة الباقية للاعتماد التجاري.

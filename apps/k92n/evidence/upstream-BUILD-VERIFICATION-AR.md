# K92N 1.0.1 — تقرير البناء والتشغيل الفعلي

## النتيجة

- .NET SDK 10.0.100 ثُبت محليًا من برنامج تثبيت Microsoft الرسمي.
- `dotnet build ... -c Release`: PASS، صفر تحذيرات وصفر أخطاء.
- `dotnet run --project tests/K92N.Tests ...`: PASS، 19 سيناريو، صفر فشل.
- اختبارات SQLite وأدوات Python: PASS، 40 حالة.
- `dotnet publish -r linux-x64 --self-contained true`: PASS؛ ملف تشغيل Linux x64 ومكتباته في release/linux-x64.
- اختبارات HTTP على الحزمة المبنية نفسها: PASS، 32 تحققًا، قاعدة مؤقتة، ورمز مشغّل مولّد لم يظهر في السجلات.
- NuGet audit للـpackage graph المستعاد: لم يبلغ عن حزم متأثرة بثغرات معروفة وقت الفحص. ليس هذا تدقيق نظام تشغيل أو runtime كاملًا.
- Docker: NOT_RUN، لا CLI ولا managed daemon/socket متاحان للمستخدم غير الجذر في هذه الجلسة.
- `PRODUCTION_READY = FALSE`؛ بوابات OIDC/RBAC والهجرة والهاتف والاستعادة التشغيلية والإنتاج باقية.

## أخطاء ظهرت وأُصلحت

1. محاولة البناء الأولى توقفت عند NU1903 بسبب SQLitePCLRaw.lib.e_sqlite3 2.1.11. أضيف اعتماد مباشر مثبت لـ3.53.3 بدل تعطيل التدقيق أو إلغاء TreatWarningsAsErrors. الاختبار الفعلي أعلن `SQLITE_NATIVE_VERSION=3.53.3`.
2. بعد restore ظهر خطآن CS8604 في التعامل مع currency قد تكون null. أُضيف رفض صريح للعملة المفقودة، وأصبح المتغير الممرر للرأس مثبتًا بعد التحقق؛ لم تُخف التحذيرات بعامل null-forgiving.
3. أضيفت ملفات packages.lock.json وDirectory.Build.props لإعادة تثبيت الرسم الاعتمادي. Dockerfile ينسخ إعدادات البناء وملفات القفل ويستخدم restore locked-mode؛ تعديل الملف ليس دليل بناء Docker.

مرجع التحذير الأول: https://github.com/advisories/GHSA-2m69-gcr7-jv3q . الإصدارات/التصحيح أعلاه موثقة أيضًا بملفات القفل ونتيجة تشغيل المكتبة، ولا يُستنتج منها غياب جميع المخاطر.

## نطاق HTTP

اختُبرت الصحة، 401 عند غياب/خطأ الرمز، حالة مشغّل صحيحة، no-store، تقديم HTML عربي مع CSP، إنشاء الحسابات ورفض تكرارها، ترحيل ذري، retry بنفس id، تعارض المفتاح، رفض السالب والدقة الزائدة وعدم التوازن والحساب المجهول والتاريخ غير الصالح، rollback، الرصيد، JSON معطوب، العكس ورفض عكس ثانٍ، سلامة السلسلة، تصفير الذمم بعد العكس، مرسى خارجي مخالف، أحداث الحوكمة، replay حتمي، تصدير السجل، منع ادعاء VERIFIED، وإقفال الفترة.

اختبار GET للواجهة لا يثبت التفاعل في Safari أو صلاحية الهاتف دون إنترنت. لا يوجد نشر عام جديد في هذه المهمة.

## التشغيل

```bash
export K92N_OPERATOR_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
./tools/run-published.sh
```

الخادم على http://127.0.0.1:5080 افتراضيًا. احتفظ بالرمز في بيئة المشغّل ولا ترسله في رابط أو log. هذا ملف تشغيل Linux x64؛ يلزم نظام ومكتبات native متوافقة. لا يحتاج SDK لتشغيل الحزمة المنشورة.

Docker يحتاج بيئة يتوفر فيها daemon وصلاحية الوصول إليه. عند توفرها، شغّل build وrun واختبار HTTP على الحاوية وسجل النتيجة؛ لا تستبدل هذا الاختبار بنتيجة تشغيل Linux المباشر.
